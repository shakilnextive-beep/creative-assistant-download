## Install করার নিয়ম

**Mac**
1. .dmg ফাইলে double-click → "Creative Assistant" টেনে "Applications"-এ ছাড়ুন।
2. Applications থেকে খুলুন। "Apple could not verify…" এলে: Done → System Settings → Privacy & Security → নিচে **Open Anyway** → Open।

**Windows**
1. setup.exe-তে double-click। নীল "Windows protected your PC" এলে: **More info → Run anyway**।
2. Next → Install → Finish।

**তারপর:** Creative Assistant-এ **Install All** → Premiere Pro খুলুন → Window → Extensions → **Premiere Bar**।
Photoshop-এ: Plugins → **PS Bar**।

## Update
নতুন update এলে Pr Bar / PS Bar-এর নামের পাশে **লাল বিন্দু** আর **Update** দেখাবে। Click করলে Creative Assistant খুলবে,
সেখানে **Update** চাপুন, তারপর Premiere / Photoshop একবার বন্ধ করে আবার খুলুন। এখানে আর আসতে হবে না।

## জরুরি কথা
- Voice Enhance, Pr Track, Pr Subtitle চলার সময় Creative Assistant খোলা রাখুন।
- Pr Subtitle-এর জন্য নিজের ফ্রি Google Gemini key লাগবে: aistudio.google.com/apikey → Create API key → Pr Subtitle-এর ⚙-এ paste।
- বাংলা template-এর জন্য "Li Ador Noirrit" font install করা থাকতে হবে।
- Premiere Pro 2022 বা পরের version (2026-এ পরীক্ষা করা)। PS Bar: Photoshop 2023 বা পরের।
